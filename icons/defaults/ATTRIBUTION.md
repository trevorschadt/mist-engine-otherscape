# Icon sources

Game-icons.net artwork is referenced directly from the required game-icons-net module at modules/game-icons-net/whitetransparent/. No copies of those icons are bundled here. See that module for source artwork and author/license information.

Direct references: id-card.svg, briefcase.svg, book-cover.svg, card-pick.svg, upgrade.svg, power-lightning.svg, clapperboard.svg.

Self, Mythos, Noise, and Challenge symbols: Son of Oak Game Studio LLC, user-supplied Otherscape Garage Style Guide. Existing vector extractions recolored; no background added.

Crew icon: user-provided group silhouette, embedded losslessly. SVG color filter displays black as white and green as transparent, preserving the original shape and antialiasing.
